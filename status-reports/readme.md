## What Each Report Covers

Each status report gives a snapshot of the project at that point in time:

- **Summary:** overall project health and highlights
- **Completed:** work finished since the last report
- **In Progress:** work currently underway
- **Up Next:** planned work for the coming period
- **Risks & Blockers:** anything that could affect the timeline, and decisions needed from 6311arts
- **Milestones:** progress against the project timeline (see the [Milestones deck](../decks/milestones.pdf))
